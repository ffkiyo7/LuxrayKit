# 底部 Tab 与软键盘解耦设计

## 背景

Task 17 曾让 `BottomNav` 根据 `visualViewport` 计算 `--lk-bottom-nav-offset`，目的是在软键盘或视觉视口变化时把底栏抬到可视区域，并让正文同步增加底部留白。实际移动浏览器中，原生选择器或软键盘关闭后的 `visualViewport` 事件可能延迟、缺失或短暂携带旧值，导致偏移残留。表现为底部 Tab 停在页面中间并遮挡正文；速度线搜索选择宝可梦是已知触发路径。

桌面 Chromium 的移动尺寸模拟不会弹出真实软键盘，`innerHeight` 与 `visualViewport.height` 始终相等，因此 localhost 的 in-app browser 无法直接复现该移动端时序。

## 目标

- 底部 Tab 的最终位置只由应用布局决定，任何输入、选择、弹层、滚动或视觉视口变化都不能让它残留在页面中间。
- 软键盘不得遮住用户正在操作的搜索结果、选择列表或底部弹层。
- 完整保留长页面自动隐藏体验：向下滚动隐藏、向上滚动回显、停滚回显、页面顶部/触底强制显示，以及 Task 17 的 RAF 滚动合并和隐藏状态去重；既有阈值、延时与动画手感不变。
- 修复覆盖全项目的文字输入、宝可梦选择、图鉴搜索、队伍编辑、计算器与速度线交互，而不是只修已知页面。

## 选定方案：A+

### 1. 底部 Tab 使用稳定布局坐标

`BottomNav` 移除 `visualViewport` 监听和 `--lk-bottom-nav-offset` 写入，恢复为固定 `bottom: 0`。隐藏态只按底栏自身高度向下移出视口，不再混入视觉视口偏移。

`.safe-bottom` 只预留底栏高度与 `safe-area-inset-bottom`，不再跟随软键盘变化。这样视觉视口即使报告过期数据，也不能改变底栏或正文布局。

软键盘打开时允许系统键盘覆盖底栏。底栏不会主动上浮到内容区；键盘关闭后也不需要额外复位事件。

### 2. 键盘适配归属交互浮层

需要在键盘上方保持可用的组件自行读取 `visualViewport`，只调整自身的底部位置或最大高度，不写全局 CSS 变量：

- `PokemonPicker` 保留现有键盘感知底部弹层行为。
- 速度线宝可梦搜索列表根据视觉视口可用高度限制结果区，并保持内部滚动；不得通过改变全局底栏位置获得空间。
- 审计其他带 `autoFocus`、文字输入或底部弹层的组件。只有确实可能被键盘覆盖的结果列表或弹层才接入局部适配。

局部适配失效或浏览器不提供 `visualViewport` 时，组件回退到现有 CSS 最大高度和内部滚动，底栏布局仍保持稳定。

### 3. 职责边界

- `useAutoHideBottomNav`：只处理页面滚动方向、触底、停滚回显和显式锁定；不负责给底栏计算键盘位移。
- `BottomNav`：只渲染固定底栏及显示/隐藏动画。
- 搜索列表与弹层：负责保证当前交互内容在视觉视口内可见。
- `.safe-bottom`：只保证无键盘时页面末尾内容能够滚到固定底栏上方。

## 测试设计

遵循回归测试先行：

1. 为 `BottomNav` 添加失败用例，模拟 `visualViewport` 缩小、滚动、恢复，断言组件不注册视口位移行为、不写入全局偏移，显示态始终为 `bottom: 0`。
2. 为安全底部留白添加静态断言，确保不再引用 `--lk-bottom-nav-offset`。
3. 为速度线搜索添加组件用例，模拟较小视觉视口，断言结果区获得受限高度并可滚动，选择宝可梦后列表关闭。
4. 保留并扩充 `useAutoHideBottomNav` 回归测试，覆盖长页面向下隐藏、向上回显、停滚回显、顶部显示和触底显示；既有阈值与 idle delay 不改，防止 Task 6/17 行为回退。
5. 运行全量单测、TypeScript/Vite 构建和移动端视觉回归。
6. 在浏览器中逐页检查环境、队伍、工具、图鉴、计算器、速度线和我的页面：滚动、聚焦、输入、选择、关闭弹层后，底栏要么贴底、要么按既有自动隐藏逻辑完全移出视口，不能悬停遮挡正文。

## 验收标准

- 任何 `visualViewport` 高度、偏移或事件顺序都不会改变底部 Tab 的显示态贴底位置。
- 速度线选择宝可梦后，列表关闭，底部 Tab 回到屏幕底部且不遮挡页面。
- 软键盘打开时，当前搜索结果或选择列表仍可见、可滚动、可完成选择。
- 长页面向下滚动时底栏仍按现有手感自动隐藏，向上滚动、停滚、到达顶部或底部时仍按现有逻辑回显。
- 所有现有测试、构建和移动端视觉回归通过。
- 不引入与 Task 17 无关的页面重构或视觉调整。
