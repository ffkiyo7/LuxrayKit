## 4. 速查模式

### 4.1 拨盘 TypeDial（压平量角器）

几何与手感常量（原型实测值，直接采用）：

| 常量 | 值 | 含义 |
|---|---|---|
| STEP | 9° | 每系角距（一屏约见 7 枚药丸） |
| R_PILL | 380px | 药丸弧半径（弧心在拨盘下方） |
| R_TICK | 348px | 刻度弧半径（药丸内侧） |
| APEX_Y | 36px | 顶点药丸中心 y；容器高 106px |
| 灵敏度 | 4.9 px/deg | ≈44px 拖一格 |
| 吸附 | 220ms ease-out cubic | 松手回格 |
| 震动 | `navigator.vibrate?.(6)` | 过格触发；iOS 无此 API 自动 no-op，**不额外处理** |

- 结构：固定指针（顶点小三角，颜色 = 当前属性色）+ 固定聚光（顶点 radial 渐变，opacity ≈0.3）+ 旋转轨道（18 药丸按钮 + 刻度：每系 1 长刻度 + 3 短刻度，共 69）。
- 布局公式：角 θ = i·STEP + rotation；x = R·sinθ，y = (APEX_Y + R_PILL) − R·cosθ（两环共用同一弧心保持同心），元素自身 rotate θ。透明度 = clamp((30 − |θ|)/8, 0, 1)，|θ| 超界 `visibility:hidden`（同时使其不可点）；顶点邻近度 p = max(0, 1 − |θ|/STEP)，scale = 0.92 + 0.26p。
- 交互规格：
  - Pointer capture 横向拖动；容器 `touch-action: pan-y`（不劫持页面纵滚）。
  - 拖动过格：更新 selectedIndex → 震动 → 卡片**轻更新**（无升起动画，靠 400ms 颜色过渡跟手）。
  - 松手：吸附动画，落格后答案卡播一次升起动画（重播需 remove class → 强制 reflow → add class）。
  - 两端橡皮筋（超界位移 ×0.35）。
  - 可见药丸可直接点选（拖动累计 >6px 抑制随后的 click）。
  - 键盘 ←/→/Home/End；滚轮步进（节流 140ms）；容器 `role="slider"` + `aria-valuemin/max/now/valuetext`（如「火属性」）。
  - `prefers-reduced-motion`：吸附瞬时完成、升起动画禁用。
- React 实现提示：**拖动帧不要走 setState/重渲染**——transform/opacity 用 ref 直写 style，仅过格（selectedIndex 变化）时 setState。

## 5. 矩阵模式（从 spotlight 原型移植 + 修正）

保留：18×18 CSS grid、粘性双表头、十字聚光（选中行列高亮、其余压暗 0.48）、渐进披露（选中格 ×值、其余紧凑符号 2/½/0/•）、顶部结果条（攻/防药丸 + 效果文案 + 交换按钮）、双轴拖拽滚动、边缘渐隐、方向键漫游、44px 触控格、完整 aria。

**删除**（§0.3）：位置控制条整块（左右箭头 + 18 段轨道 + 「3–8 / 18」文案）及其 `visibleRange` 状态与计算；倍率图例整块。

**修正**（原型评审遗留）：
1. 自动居中改为**仅当目标格超出或贴近视口边缘才滚动**（scroll-into-view-if-needed 语义）；「交换」按钮触发时才平滑居中。原型是每次点击都瞬移重定位，晕。
2. 数据接 `defensiveMatchupMultiplier`/导出后的 typeMatchups；颜色/标签接 typeColors/typeLabels；删除原型内联表。
3. 全部 token 化（页/卡/边框/文本用 Tailwind 语义色），支持亮暗主题；倍率色沿用语义（×2 danger 系、×½ 蓝或 success 系、×0 accent——以暗色下可读为准微调）。
4. 删除 Google Fonts 外链与原型壳（BottomNav、product-header 等 chrome 不移植）。
5. 矩阵高度弹性化（视口计算，不写死 470px；页面本身可纵滚兜底）。

## 6. 兼容与降级

- `color-mix` / `mask-image`：现代浏览器与 iOS 16.4+ 基线内；如需保守，`@supports not (mask-image:…)` 时隐藏剪影层即可（其余层不受影响）。
- 震动仅安卓 Chrome/Edge 生效（无权限弹窗、需手势上下文，拖动满足）；iOS 无 Vibration API，可选调用天然 no-op。
- 离线：无任何外链资源；官图已在本地资产内。
