# UI 整体改造（2026-09）

设计来源：Claude Design 项目「PWA 视觉重做方向选择」的 `01`–`09` 帧 + `readme.md`。`Luxray Kit 现状复刻` 已降级为草稿，不作依据。

## 工作方式

- **分支**：长期分支 `dev`，阶段性提交，全部完成后一次性合 `main`（`main` push 即上线，不分批合）。期间定期从 `main` 同步，吸收每日数据 auto-merge。
- **验收**：push `dev` → 影子 Worker 构建 → Discord `luxraykit-dev` 收到预览链接 <https://dev-luxraykit-app-preview.ffkiyo7.workers.dev>。视觉一律由 owner 肉眼验收（见 `AGENTS.md` §3）。同一地址反复换版本，验收前先刷新一次（Service Worker 缓存）。
- **视觉基线**：改造期间 CI 的 `visual` 门禁在 `dev` 上必然是红的，属预期。合 `main` 前用 `gh workflow run visual-baseline.yml --ref dev` 一次性重建；不为改造新增回归用例。
- **取信顺序**：`01`–`09` 帧 + 下方已拍板决策 ＞ `readme.md` 里 01–09 迭代出的规则 ＞ `tokens/*.css` ＞ `components/*.jsx`、`ui_kits/`（旧于帧，仅供参考）。

## 已拍板的决策

**数据口径**（核对过 `public/data/pokedb/reg-ma-environment.json`）

| 数据 | 上游有什么 | 显示 |
| --- | --- | --- |
| 宝可梦整体排行 | 只有名次（rank-relative，第 1 名 = 100） | 名次 + 名次变化（NEW / ↑n / ↓n / –） |
| 常见队友 | rank-relative | 只排序，不标数字 |
| 招式 / 道具 / 特性 / 性格 | 真实百分比 + 采用队数，**仅名次前 60**（`detailCount`） | 百分比，一位小数，中性色（不用琥珀） |
| 样本占比 / 出现队伍 | 不存在 | 不显示 |

**产品规则**

- 属性速查：转盘砍掉，三个 tab = 单属性 / 双属性 / 完整矩阵。矩阵交互保留现有实现（44px 格、拖拽平移、吸附表头、键盘导航），只换样式。双属性「代表宝可梦」= 该组合里环境名次最高者，无上榜取图鉴号最小者。
- **满 6 只才能分享链接**；少于 6 只的旧分享链接仍可导入。
- **队伍码 = 游戏内租借码**（`src/lib/teamShare.ts`），app 不能生成也不能反查；有才显示、可复制，与成员数无关。设计稿里的「输入队伍码导入」改为「粘贴分享链接 / 分享码」（`#/t/<code>`）。
- 道具冲突 = **转移**而不是阻止保存；暂存到保存为止，取消则两只都回滚。
- **规则页重新开放**：主入口在「我的」（与「关于与数据」并列），环境页数据更新行可点作次入口。开放前 owner 先过一遍 `RulePage` 文案。
- 编辑配置改整页；返回箭头 = 取消，有未保存改动弹一次「放弃改动？」。
- 新增功能：「按热门配置加入队伍」（SP 留空，仅前 60 名）、计算器选择器「环境常用」tab（只列宝可梦，代入空白配置）、「复制为新队伍」、工具首页 04-01（保留「最近用过」，砍掉 tile 内嵌搜索）、招式分类筛选、「添加到主屏幕」（已安装隐藏；iOS 给图文说明）、环境离线态、详情页上下翻页、首开数据口径 sheet、分享链接失效页、清除本地数据确认。

**删除 / 保留**

- 删：Onboarding 整个功能、「你知道吗」横幅、前三名金银铜牌、彩蛋弹窗、队伍卡一键删除（改走 ⋯ 菜单 + 确认）。
- 保留：名次涨跌、数据状态徽标、成员卡「速度线 / 伤害计算」快捷入口、拖拽排序、图鉴详情的种族值总和 / 招式威力命中 PP / 「加入队伍」「→ 计算」。图鉴大图查看与身高体重保留（可重新设计形态）。
- 伦琴猫预设队保留：卡片尺寸与普通队伍卡一致，首次打开前带一个小标记，打开过一次后退化成普通卡。
- `hasCompletedOnboarding` 字段留在 IndexedDB 不动（无害，免迁移）。

**工程**

- 字体：Manrope 自托管（拉丁 + 数字子集），中文走系统字体；不放行任何字体外域。
- 默认主题深色，不跟随系统。
- Tab bar：保留现有 `useAutoHideBottomNav` 的全部锁定（键盘 / 输入聚焦 / sheet 打开 / 空闲回弹 / reduced-motion）；「收起」= 缩成图标胶囊，不再滑出屏幕。
